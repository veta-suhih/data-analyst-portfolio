## 📁 Мои проекты

### 1. 🏢 Анализ рынка аренды жилья в Москве (End-to-End)
**[🔗 Ссылка на репозиторий](https://github.com/veta-suhih/moscow-rental-market-analysis)**

Полный цикл исследования: парсинг данных с Циан (обход антибот-защиты через Playwright), очистка и подготовка данных, загрузка в PostgreSQL, написание сложных SQL-запросов с оконными функциями (RANK, LAG, NTILE, PERCENTILE_CONT), построение интерактивного дашборда в Power BI с DAX-мерами.

**Ключевые результаты:** Выявлен парадокс арендодателей (собственники дороже агентств на 10%), найдены недооценённые сегменты (дисконт на последний этаж — 33%), сформирована 3-уровневая стратегия выхода на рынок для агентства недвижимости.

**Стек:** Python (Pandas, BeautifulSoup), PostgreSQL, SQL, Power BI (DAX), Matplotlib, Seaborn.
