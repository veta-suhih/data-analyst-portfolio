# Data Analyst Portfolio

Портфолио проектов Junior Data Analyst.  
Стек: Python, SQL, Power BI, Yandex DataLens.

## Проекты

### 1. FinTech Transaction Analysis
Исследовательский анализ финансовых транзакций: поведение клиентов, паттерны мошенничества и рискованные категории.

**Инструменты:** Python, pandas, seaborn, matplotlib  
**Ключевые инсайты:** доля fraud 3.06%, пики риска в 5:00, 9:00 и 14:00, наиболее рискованные категории — Entertainment и Retail.

→ [Смотреть проект](https://github.com/veta-suhih/01-fintech-transaction-analysis)

---

### 2. SQL Product Analytics — Digital Media Platform
SQL-анализ цифрового медиа-сервиса (на базе Chinook). Анализ выручки, поведения клиентов, эффективности поддержки и популярности контента.

**Инструменты:** PostgreSQL, DBeaver, SQL  
**Ключевые результаты:**
- Общая выручка: $2 328.60 | Средний чек: $5.65
- Топ стран: USA, Canada, France
- Самый популярный жанр: Rock
- Все клиенты — повторные

→ [Смотреть проект](https://github.com/veta-suhih/02-sql-product-analytics)

---

### 3. SaaS Product Analytics Dashboard
Интерактивный дашборд по SaaS-метрикам: MRR, ARR, churn, использование продукта и поддержка.

**Инструменты:** Power BI, Power Query, DAX  
**Что внутри:**
- 3 страницы дашборда
- Анализ выручки, клиентов и оттока
- Product Health и причины churn

→ [Смотреть проект](https://github.com/veta-suhih/03-product-dashboard)
