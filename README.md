## 📁 Мои проекты

### 1. 🏢 Анализ рынка аренды жилья в Москве (End-to-End)
**[🔗 Ссылка на репозиторий](https://github.com/veta-suhih/moscow-rental-market-analysis)**

Полный цикл исследования: парсинг данных с Циан (обход антибот-защиты через Playwright), очистка и подготовка данных, загрузка в PostgreSQL, написание сложных SQL-запросов с оконными функциями (RANK, LAG, NTILE, PERCENTILE_CONT), построение интерактивного дашборда в Power BI с DAX-мерами.

**Ключевые результаты:** Выявлен парадокс арендодателей (собственники дороже агентств на 10%), найдены недооценённые сегменты (дисконт на последний этаж — 33%), сформирована 3-уровневая стратегия выхода на рынок для агентства недвижимости.

**Стек:** Python (Pandas, BeautifulSoup), PostgreSQL, SQL, Power BI (DAX), Matplotlib, Seaborn.

### 2. 🛒 Анализ воронки продаж и A/B-тестирование (Ozon E-commerce)
**[🔗 Ссылка на репозиторий](https://github.com/veta-suhih/ecommerce-funnel-ab-test)**

End-to-end продуктовая аналитика на данных крупного маркетплейса (40 млн событий, 18 млн заказов): разведочный анализ (EDA), построение строгой последовательной воронки продаж через SQL (CTE, COUNT(DISTINCT)), дизайн A/B-теста с расчётом размера выборки, проверка SRM, z-тест для конверсии, t-тест для ARPU и сегментный анализ.

**Ключевые результаты:** Найдено узкое место воронки — конверсия из просмотра в корзину ~52%, медианное время до покупки — 4.47 дня, пик заказов — воскресенье и среда. A/B-тест показал статистически значимый прирост конверсии (p < 0.05) и ARPU (p < 0.001). Сегментный анализ выявил разнонаправленный эффект в будни и выходные — рекомендована раскатка с мониторингом.

**Стек:** Python (Pandas, NumPy, SciPy, Statsmodels), PostgreSQL, SQL, Jupyter Notebook, Matplotlib, Seaborn, Plotly.
